# TripPilot

**Category:** Full-Stack Development, Artificial Intelligence, Automation

**Status:** Functional application

## Overview

TripPilot is a full-stack travel intelligence platform that helps users plan trips, manage itineraries, and monitor travel costs.

The application combines AI-generated travel itineraries with automated flight and hotel price monitoring.

## Technologies Used

- Next.js, React, TypeScript, and Tailwind CSS
- Supabase and PostgreSQL
- Google Gemini API
- GitHub Actions
- Resend Email API
- Vercel

## Key Features

### AI-Powered Itinerary Generation

Uses Google's Gemini API to generate travel itineraries based on trip information.

### Automated Price Monitoring

Monitors flight, hotel, and combined trip prices against user-defined price thresholds.

### Email Alerts

Sends automated email notifications when price conditions are met.

### Trip Management

Allows users to save, view, and delete trips through a persistent database.

### Price History

Stores pricing information to help users evaluate changes in travel costs.

## Technical Highlights

- Developed a full-stack application with Next.js and TypeScript.
- Integrated Supabase for persistent trip data.
- Implemented scheduled monitoring workflows with GitHub Actions.
- Connected external APIs for AI-generated itineraries and travel information.
- Deployed the application using Vercel.
